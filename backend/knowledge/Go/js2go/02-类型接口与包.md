# JS 转 Go：类型、接口与包

> **本页关键词**：零值、切片、map、struct、隐式接口、`any`、类型断言、指针接收者、大小写可见性、go.mod、internal

---

## 一、静态类型在干什么

JS 的值可以换类型；Go 不行。好处是很多错误编译期就爆，代价是要学会切片、接口、指针这套词汇。

常用类型对照：

| JS | Go | 零值 |
| --- | --- | --- |
| `number` | `int` / `int64` / `float64` 等 | `0` / `0.0` |
| `string` | `string`（不可变，按字节 `len`） | `""` |
| `boolean` | `bool` | `false` |
| `null` / `undefined` | `nil`（只给引用类型） | — |
| `Array` | `[n]T` 数组（定长）或 `[]T` 切片 | 数组全零；切片 `nil` |
| `Object` / `Map` | `struct` / `map[K]V` | 结构体字段零值；map `nil` |
| 任意值 | `any`（即 `interface{}`） | `nil` |

日常几乎只用 `int`、`int64`、`float64`。需要固定宽度再写 `int32`/`uint8`（例如协议、二进制）。

字符串是只读字节序列。中文按 rune 遍历：`for _, r := range s`。`len(s)` 是字节数，不是字符数。

## 二、复合类型

### 数组 vs 切片

数组 `[n]T` 长度是类型的一部分，`[3]int` 和 `[4]int` 不是同一种类型。几乎总是用切片。

```go
s := []int{1, 2, 3}
s = append(s, 4)     // 必须接返回值
sub := s[1:3]        // 和底层数组共享，改 sub 可能改 s
a := [3]int{1, 2, 3}
s2 := a[:]           // 数组转切片
```

切片三个字段：**指针、len、cap**。`append` 容量不够会新分配数组，旧切片看不到新元素。两个切片共享底层数组时，原地修改会互相影响。

`make([]int, 0, 16)` 预分配 cap，减少扩容。不要用 `==` 比较切片，只能和 `nil` 比，或用 `slices.Equal`。

### map

```go
m := make(map[string]int)
m["a"] = 1
v, ok := m["a"] // 逗号 ok，区分「没这个键」和「值就是零值」
delete(m, "a")
```

未 `make` 的 `nil` map 读得到零值，**写会 panic**。遍历顺序每次都可能变。键必须可比较，不能用切片当键。

### 结构体

```go
type User struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

u := User{Name: "Ada", Age: 30}
```

用字段名初始化，少用按位置。Go 没有 class / 继承，复用靠**嵌入**：

```go
type Person struct{ Name string }
func (p Person) Greet() string { return "hi " + p.Name }

type Employee struct {
    Person
    Salary int
}
// emp.Greet()、emp.Name 可直接用，等于组合而不是 IS-A
```

> **面试要点**：JSON 只导出**大写字段**。`name string` 序列化会丢；要小写键名用 tag：`` `json:"name"` ``。

## 三、接口

Go 接口是**方法集合**，满足是隐式的：类型不用声明 `implements`，有方法就算。

```go
type Measurable interface {
    Area() float64
}

type Circle struct{ Radius float64 }

func (c Circle) Area() float64 { return math.Pi * c.Radius * c.Radius }

func printArea(m Measurable) { fmt.Println(m.Area()) }

printArea(Circle{Radius: 5}) // Circle 没写 implements
```

接口可嵌套：`type ReadWriter interface { Reader; Writer }`。标准库 `io.Reader` / `http.Handler` 都是小接口。

`any`（`interface{}`）能装任何值，等于放弃静态信息，取出要用断言：

```go
var v any = "hello"
s := v.(string)        // 失败则 panic
s, ok := v.(string)    // 推荐
switch x := v.(type) { // 类型 switch
case string:
    _ = x
case int:
    _ = x
}
```

原笔记问过：`map[string]interface{}` 的 `interface` 是干什么的？就是「值的类型到运行时再定」，接近 JS 对象。能用具体类型就不要用 `any`。

> **面试要点**：接口值内部是 `(动态类型, 动态值)`。把 `nil` 指针赋给接口后，接口**不是 nil**（类型还在）。这是 `if err != nil` 的经典坑，见第 6 篇。

## 四、指针

JS 对象默认引用传递；Go 默认**拷贝值**。要改调用方的结构体，用指针。

```go
n := 42
p := &n  // *int，指向 n
*p = 100 // n 变成 100

func scale(r *Rect, k int) { r.W *= k }

func (r *Rect) Scale(k int) { r.W *= k } // 指针接收者，可改接收者
func (r Rect) Area() int    { return r.W * r.H } // 值接收者，改的是副本
```

规则：

- 要改接收者，或结构体较大，用指针接收者。
- 同一类型的方法接收者尽量统一，不要有的 `T` 有的 `*T`。
- 零值指针是 `nil`，解引用 `*p` 会 panic，先判空。
- Go 有 GC，没有 `free`，也没有指针运算。

方法集：`*T` 的方法，值 `T` 也能调（编译器取地址）；反过来，若只有值接收者，接口变量里若是指针也能调。面试常问「为什么接口装值/指针有时编不过」：看方法集是否包含接口要求的方法。

## 五、包与可见性

同一目录所有 `.go` 必须同一个 `package` 名。导入的是**包**，不是文件。

```go
package utils

var Public = 1  // 包外可见
var hidden = 2  // 仅包内
```

**首字母大写 = 导出**（类似 `export`），小写 = 包私有。结构体字段同样。没有 `export default`。

特殊目录：

| 目录 | 含义 |
| --- | --- |
| `internal/` | 只有 `internal` 的父树能 import，编译器强制 |
| `cmd/xxx/` | 可执行入口，一个子目录一个二进制 |
| `pkg/` | 社区约定的对外库，不是关键字 |

导入：

```go
import (
    "fmt"
    "github.com/gin-gonic/gin"
    myfmt "fmt"                 // 别名
    _ "github.com/lib/pq"       // 只跑 init，注册驱动
)
```

点导入 `. "fmt"` 会污染命名空间，生产代码别用。循环 import 直接编译失败，用接口解耦或抽第三包。

## 六、模块：go.mod 对照 npm

| | npm | Go |
| --- | --- | --- |
| 清单 | `package.json` | `go.mod` |
| 锁 | `package-lock.json` | `go.sum`（哈希） |
| 包名 | `express` | `github.com/gin-gonic/gin` |
| 安装位置 | `node_modules/` | 模块缓存 `$GOPATH/pkg/mod` |
| 加依赖 | `npm i express` | `go get github.com/gin-gonic/gin` |
| 清理 | 手工 | `go mod tidy` |

```bash
go mod init github.com/you/app
go get github.com/gin-gonic/gin@v1.9.1
go mod tidy
go list -m all
```

模块路径就是 import 路径，clone 下来就能编译，不经过中央注册表（proxy 只是缓存）。版本用 Git tag，如 `v1.2.3`。

`go work` 用来本地同时开发多个 module，相当于简单 monorepo，了解即可。`vendor/` 是把依赖拷进仓库，CI 离线构建才需要。

> **面试要点**：导出靠大小写不是风格问题，是语言规则；JSON、跨包调用、测试里的 `Foo`/`foo` 全跟它挂钩。
