## 题意与示例

### 239. 滑动窗口最大值

[题目链接](https://leetcode.cn/problems/sliding-window-maximum/)：长度为 `k` 的窗口从左向右滑动，返回每个窗口中的最大值。

> 示例：输入 `nums = [1,3,-1,-3,5,3,6,7], k = 3`，输出 `[3,3,5,5,6,7]`。

### 2398. 预算内的最多机器人数目

[题目链接](https://leetcode.cn/problems/maximum-number-of-robots-within-budget/)：连续运行机器人的成本为最大充电时间加数量乘运行成本之和，求预算内的最大连续数量。

> 示例：输入 `chargeTimes = [3,6,1,3,4], runningCosts = [2,1,3,4,5], budget = 25`，输出 `3`。

### 862. 和至少为 K 的最短子数组

[题目链接](https://leetcode.cn/problems/shortest-subarray-with-sum-at-least-k/)：求元素和至少为 `k` 的最短非空连续子数组长度，不存在则返回 -1。

> 示例：输入 `nums = [1], k = 1`，输出 `1`。

### 1499. 满足不等式的最大值

[题目链接](https://leetcode.cn/problems/max-value-of-equation/)：在横坐标差不超过 `k` 的点对中，求 `yi + yj + |xi - xj|` 的最大值。

> 示例：输入 `points = [[1,3],[2,0],[5,10],[6,-10]], k = 1`，输出 `4`。

### 1696. 跳跃游戏 VI

[题目链接](https://leetcode.cn/problems/jump-game-vi/)：从下标 0 出发且每次最多前进 `k` 步，求到达末尾时经过元素和的最大值。

> 示例：输入 `nums = [1,-1,-2,4,-7,3], k = 2`，输出 `7`。

### 2944. 购买水果需要的最少金币数

[题目链接](https://leetcode.cn/problems/minimum-number-of-coins-for-fruits/)：购买第 `i` 个水果可免费获得后续指定范围的水果，求拿到全部水果的最少金币数。

> 示例：输入 `prices = [3,1,2]`，输出 `4`。
