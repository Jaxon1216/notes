## 题意与示例

### 122. 买卖股票的最佳时机 II

[题目链接](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/)：允许完成任意次股票交易但最多持有一股，求最大利润。

> 示例：输入 `prices = [7,1,5,3,6,4]`，输出 `7`。

### 309. 买卖股票的最佳时机含冷冻期

[题目链接](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/)：允许多次交易但卖出后一天不能买入，求最大利润。

> 示例：输入 `prices = [1,2,3,0,2]`，输出 `3`。

### 188. 买卖股票的最佳时机 IV

[题目链接](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/)：最多完成 `k` 笔股票交易，求最大利润。

> 示例：输入 `k = 2, prices = [2,4,1]`，输出 `2`。

### 714. 买卖股票的最佳时机含手续费

[题目链接](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/)：允许多次交易且每笔交易支付手续费 `fee`，求最大利润。

> 示例：输入 `prices = [1,3,2,8,4,9], fee = 2`，输出 `8`。

### 2826. 将三个组排序

[题目链接](https://leetcode.cn/problems/sorting-three-groups/)：数组只含 1、2、3，求删除最少元素使剩余序列非递减。

> 示例：输入 `nums = [2,1,3,2,1]`，输出 `3`。

### 2786. 访问数组中的位置使分数最大

[题目链接](https://leetcode.cn/problems/visit-array-positions-to-maximize-score/)：从下标 0 开始向右选择位置并累加值，每次切换奇偶性扣除 `x`，求最大得分。

> 示例：输入 `nums = [2,3,6,1,9,2], x = 5`，输出 `13`。
