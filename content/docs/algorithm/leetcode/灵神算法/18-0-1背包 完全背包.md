## 题意与示例

### 494. 目标和

[题目链接](https://leetcode.cn/problems/target-sum/)：给每个数字添加正号或负号，统计表达式结果等于 `target` 的方案数。

> 示例：输入 `nums = [1,1,1,1,1], target = 3`，输出 `5`。

### 322. 零钱兑换

[题目链接](https://leetcode.cn/problems/coin-change/)：每种硬币可无限使用，求凑成 `amount` 所需的最少硬币数。

> 示例：输入 `coins = [1,2,5], amount = 11`，输出 `3`。

### 2915. 和为目标值的最长子序列的长度

[题目链接](https://leetcode.cn/problems/length-of-the-longest-subsequence-that-sums-to-target/)：求元素和恰好为 `target` 的最长子序列长度，不存在则返回 -1。

> 示例：输入 `nums = [1,2,3,4,5], target = 9`，输出 `3`。

### 416. 分割等和子集

[题目链接](https://leetcode.cn/problems/partition-equal-subset-sum/)：判断正整数数组能否分成元素和相等的两个子集。

> 示例：输入 `nums = [1,5,11,5]`，输出 `true`。

### 518. 零钱兑换 II

[题目链接](https://leetcode.cn/problems/coin-change-ii/)：每种硬币可无限使用，统计凑成 `amount` 的不同组合数。

> 示例：输入 `amount = 5, coins = [1,2,5]`，输出 `4`。

### 279. 完全平方数

[题目链接](https://leetcode.cn/problems/perfect-squares/)：求和为 `n` 所需的最少完全平方数数量。

> 示例：输入 `n = 12`，输出 `3`。
