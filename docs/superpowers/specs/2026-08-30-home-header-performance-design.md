# 首页导航与性能优化设计

## 目标

- 首页导航覆盖在首屏背景上，保持透明并与粒子背景连成一体。
- `/docs/**` 等非首页路由继续使用 Fumadocs 主题变量和不透明背景，保证正文可读性。
- 收敛首页持续动画带来的 CPU/GPU 占用，并确保组件卸载后不残留动画任务。
- 补全“参与文档贡献”页面的仓库地址和 PR 流程。

## 实现

首页路由由 `.home-shell` 标识。使用 CSS `body:has(.home-shell)` 切换导航定位和外观，避免为了判断路由把整个导航改成客户端组件。首页导航使用 `position: fixed`、透明背景和无边框样式；首屏恢复为完整视口高度，并为导航预留顶部空间。非首页导航维持 `sticky`，使用不透明的 Fumadocs 背景色。

粒子背景降低桌面和移动端粒子数量，初始化时遵循 `prefers-reduced-motion`，组件卸载时调用 particles.js 的销毁逻辑。LogoLoop 在减少动态效果偏好或页面不可见时停止 `requestAnimationFrame`，页面重新可见后恢复。

贡献文档增加正确的 GitHub 仓库链接、Fork、分支、提交、推送和创建 PR 的完整步骤，并列出 PR 描述与自检要求。全站 GitHub 入口同步指向当前仓库。

## 验证

- 运行内容、图片、类型和生产构建检查。
- 静态检查首页与文档页选择器、动画清理逻辑和仓库链接。
- 不使用浏览器自动化或视觉对比，遵循本次用户选择。
