# AI 协作贡献规范

本文是使用 AI 编程工具向 Easton Notes 投稿或修改内容时的唯一参考规范。它补充
`AGENTS.md`、`docs/writing-style.md` 和 `docs/pull-request.md`，不替代其中已有的目录、
标题和提交要求。

## 适用方式

先在本机准备原始面经、八股草稿或资源链接，再打开自己 Fork 后的仓库，让 AI 在工作区内完成
整理。开始前，AI 必须先读取 `AGENTS.md`、`docs/agent-index.md`、`docs/writing-style.md`，
并确认目标目录；不要把原始材料直接交给 AI 后就提交生成结果。

AI 先说明计划写入或修改哪些文件。完成后，贡献者必须自行阅读 `git diff`，确认事实、隐私信息、
链接和排版均正确，再提交 PR。

## 面经整理规范

- 只依据原始记录整理，不搜索网络，不新增题目、追问、答案、技术细节、面试结果或评价。
- 保留题目、追问、候选人回答和事件的原始顺序；“记不清”“大概”等不确定信息必须保留。
- 原文没有答案时只保留问题；已有回答只能润色表达，不能改写成标准答案。
- 只修正不改变原意的明显错别字、标点、口语赘词和 Markdown 排版。
- 对姓名、电话、邮箱、账号、密钥、精确住址、未公开内部项目与链接做必要脱敏；无法判断时保留原文并提醒贡献者确认。
- 面经放在对应方向的 `content/docs/<direction>/interview/`。长文按自然的公司、轮次或主题使用
  `##` 和必要的 `###` 分组；不要为了目录强行拆分，也不要添加多个 `#`。

## 八股和知识文章规范

- 先判断主题所属方向，再放到 `content/docs/<direction>/knowledge/`；Agent 应用工程与 LLM 原理分别使用
  `content/docs/agent/knowledge/agent/` 和 `content/docs/agent/knowledge/llm/`。
- 保留原始材料已经确认的结论和示例。信息不足时标注“待补充”或向贡献者提问，不得把猜测写成事实。
- 使用一个文章标题和逐级下降的 `##`、`###` 标题；代码示例使用带语言标识的代码块。
- 图片放在当前专题附近的 `img/` 目录，使用 `./img/filename` 相对路径，并提供有意义的 alt 文案。

## 资源推荐规范

资源推荐放在对应方向的 `content/docs/<direction>/resources/`，每篇推荐必须有可访问的原文或项目链接、
2 至 5 句推荐理由和标签。AI 不得编造链接、作者、项目状态或阅读感受；无法验证的链接应交给贡献者确认。

推荐结构如下：

```markdown
# 推荐标题

## 链接

- 原文或项目：<https://example.com>

## 推荐理由

说明它解决了什么问题、适合谁读，以及为什么值得收录。

## 标签

- React
- 工程化
```

## 交付前检查

AI 完成修改后，贡献者应依次确认：

- 文件是否位于正确的内容目录；新增目录是否真的需要 `meta.json`。
- 标题层级、代码块、图片引用和链接是否符合写作规范。
- `git diff` 是否只包含本次贡献，不含构建产物、编辑器配置或无关的导航、样式和架构改动。
- 已运行 `npm run check:content`、`npm run check:images`；涉及导航、目录、样式或构建链路时已运行
  `npm run docs:build`。提交 PR 前建议运行 `npm run validate`。

## 可复制提示词

将下面提示词与原始材料一起交给已打开本仓库的 AI 编程工具：

```text
请把下面材料整理为 Easton Notes 的一次内容贡献。

先读取 AGENTS.md、docs/agent-index.md、docs/writing-style.md 和 docs/ai-contribution.md；
先说明材料类型、目标目录和预计修改的文件，等待我确认后再写入。

整理要求：
1. 面经只忠实整理原始题目、追问、回答和顺序；不补写事实或标准答案，并提示需要我确认的脱敏项。
2. 八股只保留原文可确认的信息；不确定内容标记为待补充，不自行编造。
3. 资源推荐必须包含原文或项目链接、推荐理由和标签；不编造链接或评价。
4. 遵守仓库的目录、标题、代码块、图片和 meta.json 规范，不修改无关导航、样式、架构或他人改动。

写入后请汇报：修改的文件、内容归档理由、未能确认的问题，以及建议运行的检查命令。

原始材料：
<在这里粘贴内容>
```
