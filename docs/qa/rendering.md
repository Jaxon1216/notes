# 渲染与 Hydration

## 标题内链接导致 `<a>` 嵌套

- 现象：Console 报 `In HTML, <a> cannot be a descendant of <a>` 或 `a cannot contain a nested <a>`。
- 原因：Markdown 标题里写了 `[text](url)`，Fumadocs 标题组件又会给标题生成锚点链接。
- 处理：标题只保留纯文本，把链接移到标题下方普通段落。
- 检查：`rg -n "^#{1,6} .*\\[[^\\]]+\\]\\(" content/docs -g "*.md" -g "*.mdx"` 应无输出；必要时跑 `npm run build`。

## AI 回答高亮后代码意外换行

- 现象：围栏代码的一行被拆成多个块，关键字和字符串之间出现额外空白。
- 原因：语法高亮生成嵌套 `span`，命中消息标签的后代选择器并继承 `display: block` 等布局属性。
- 处理：消息标签使用 `.ai-explain-message > span`，只匹配直接子元素。
- 检查：渲染含 TypeScript 代码与长表格的 AI 回答，确认高亮 token 的计算样式为 `display: inline`、无额外外边距，表格在自身容器内横向滚动。

## 流式回答导致追加引用入口消失

- 现象：AI 回答生成中划选正文，“追加引用”入口随下一次消息区滚动消失。
- 原因：捕获阶段的全局 `scroll` 监听也收到侧栏内部滚动，误将正文选区位置判为失效。
- 处理：忽略正文及其祖先容器之外的元素滚动，保留页面、正文滚动和窗口缩放时的清理。
- 检查：划选正文后滚动侧栏，选区浮标应保留；滚动正文或页面，浮标应清除。运行 `npm run test:unit` 验证事件边界回归用例。
